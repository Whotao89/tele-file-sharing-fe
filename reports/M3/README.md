# Bài báo cáo lần 3
## Nội dung chỉnh sửa cuối cùng
- Thêm vào [cách hướng dẫn tải sops và age về để giải mã dev.enc](https://github.com/dath-251-thuanle/tele-file-sharing-fe/blob/MILESTONE-M3/env/README.md).
- Thêm các command như /uploadhistory để xem lịch sử upload và /myshares để xem danh sách chia sẻ.
- Thêm command có sẵn như `Quản lý Share Link` để tiện xem danh sách thông tin chia sẻ (Biểu tượng kế bên Paperclip sẽ hiện lên 3 command có sẵn là `Quản lý File`, `Trợ giúp` và cái mới thêm vô `Quản lý Share Link`).
- Thêm attribute RequiredPassword vô ShareMetadataResponse model để kiểm tra đường dẫn chia sẻ có cài đặt mật khẩu hay không.
